# AlibiMasters

Первая локальная версия сайта выездной ролевой игры «Мафия» в Геленджике. Сайт показывает форматы, условия, стоимость и контакты. Настоящий приём заявок пока не подключён.

## Требования

- Node.js 20.9 или новее (рекомендуется Node.js 24)
- npm 11 или совместимый менеджер пакетов

## Установка и запуск

```powershell
npm install
npm run dev
```

После запуска откройте адрес, который напечатает Next.js (обычно `http://127.0.0.1:3000`). Для production-сборки:

```powershell
npm run typecheck
npm run lint
npm run build
npm run start
```

В текущей среде Node.js установлен без команды `npm`, поэтому для разработки использовался npm CLI из официального npm Registry. Если зависимости уже установлены, локальный сервер можно запустить напрямую:

```powershell
node node_modules/next/dist/bin/next dev --hostname 127.0.0.1
```

## Что доступно

- Главная страница `/` и страница корпоративов `/corporate`.
- Калькулятор стоимости: 4 000 ₽/час, минимум 2 часа.
- Демонстрационная форма с проверкой полей и прямыми ссылками на телефон и Telegram.
- Условия бронирования `/terms` и проект политики `/privacy`.
- Адаптивная навигация, базовое SEO, sitemap и robots.
- `/admin` возвращает 404 до появления защищённой панели.

## Ограничения первой версии

Форма не отправляет данные и не сохраняет заявки. Для бронирования нужно связаться по телефону или в Telegram. Галерея состоит из явно отмеченных иллюстраций. Политику конфиденциальности необходимо заполнить и проверить юридически до подключения настоящей формы. Домен `alibimasters.ru` пока не подтверждён; перед публикацией установите `NEXT_PUBLIC_SITE_URL` на фактический адрес сайта и пересоберите проект.

Никаких оплат на сайте нет: оплата только наличными при проведении мероприятия.
