# Ход разработки

## Реализовано в этапе A

- Страницы `/`, `/corporate`, `/privacy`, `/terms`.
- Адаптивная навигация, разделы главной страницы, демонстрационная галерея и FAQ.
- Калькулятор с почасовым тарифом и минимальной длительностью.
- Демонстрационная форма с проверкой обязательных полей, телефона, даты, длительности и согласия.
- Метаданные, sitemap, robots и закрытый до авторизации маршрут `/admin`.

## Демонстрационный режим

- Форма не отправляет и не сохраняет заявку.
- Галерея использует декоративные иллюстрации, а не фотографии мероприятий.
- Юридические сведения в политике конфиденциальности помечены для заполнения.

## Проверки

- `npm install`: успешно, 367 пакетов. В этой среде npm CLI запускался через Node.js из скачанного официального пакета npm; обычная команда `npm` не была установлена.
- `npm run typecheck`: успешно.
- `npm run lint`: успешно, без предупреждений после исправления конфигурации PostCSS.
- `npm run build`: успешно на Next.js 16.4.6 после ограничения числа рабочих процессов до одного. Промежуточные попытки сборки завершались ошибкой `EPERM` при параллельном создании служебных каталогов в этой Windows-среде.
- Production-сервер `npm run start`: успешно запущен на `http://127.0.0.1:3000`.
- HTTP: `/`, `/corporate`, `/privacy`, `/terms`, `/sitemap.xml`, `/robots.txt` — `200`; `/admin` — `404`.
- Браузер: проверены первый экран на компьютере и телефоне, мобильное меню, пересчёт 2 → 3 часа (8 000 → 12 000 ₽), ошибки пустой формы и сообщение «заявка не отправлена» после корректного заполнения.
- Браузер: проверены мобильные `/corporate`, `/privacy`, `/terms`; исправлено обрезание текста на странице корпоративов. На проверенных страницах ширина содержимого не превышала ширину мобильного viewport.
